## One proposed rule

For a scheduled one-coordinate proposal, form the control's set of unissued neighbors around its best measured full-fidelity recipe. For each eligible coordinate, count the distinct earlier **local proposals issued from that exact incumbent** that changed that coordinate. Keep the coordinates with the smallest count, then select the neighbor with the highest existing acquisition score among them. Shuffle the original neighbor list once using the control's seeded RNG and preserve that order to break score ties. Record the chosen coordinate when the proposal is issued, including if its evaluation later fails. Counts are scoped to campaign and incumbent recipe and persist if that recipe becomes incumbent again. Global, crossover and promotion trials do not increment them. If the control has no eligible local neighbor, use its existing fallback.

**Prediction:** under the fixed budget, the proposed policy will increase mean best full-fidelity search accuracy over the corrected portfolio and beat both baselines. Diversifying coordinates can cost a productive second move along the same coordinate. Seed 11 motivated the proposal and is development evidence.
