# Evaluation authority

A successful process produces descriptive measurements. An authorized evaluator
can turn those measurements into an evaluation receipt. Promotion is a separate decision.

Declare `expected_members` in the manifest's evaluation section. This set identifies
the complete evaluation panel. Older manifests still parse, but cannot authorize
evaluation until they declare the panel.

## Procedure

1. Wait for the evaluation job's inputs and dependencies to become available.
2. Call `evaluation.authorize` with its job ID, current revision, and evaluator principal ID.
3. Dispatch the job through its registered worker.
4. Call `evaluation.complete` as the designated evaluator with the request ID and completed attempt ID.

Authorization requires `evaluation.request`, `read`, and `artifact.upload`.
The upload permission covers the immutable input manifest generated by the controller.
Completion requires `evaluation.publish` and `read`. Worker credentials do not grant evaluator authority.

Authorization freezes the input artifact set, experiment digest, seed, metric schema,
expected panel, and evaluator identity before worker admission. It cannot certify an
already admitted or completed attempt. A confirmation request must use a declared
confirmation seed. The statistical plan must additionally govern selection and exposure.

Completion reads the verified report of the accepted attempt. Callers cannot supply
replacement measurements. The service checks the execution identity and records one
receipt per request. Repeated delivery returns that receipt.

An incomplete panel produces an incomplete receipt. Changed metric semantics produce
invalid evidence. Both remain queryable. Neither is a successful scientific comparison.

## Trust boundary

The current profile authenticates the evaluator and binds its report to execution.
It does not isolate hostile training code from all evaluator resources. Protected and
self-reported profiles are not qualified by this service. Trusted local execution
and protected evaluation remain distinct claims.
