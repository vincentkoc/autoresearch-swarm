## Contract scenarios

The suite covers schemas, artifacts, source, manifests, budgets, native supervision,
journals, resources, workloads, controller commands, evaluation, selection, and
SDK transports. It includes real process, deadline, race, and restart scenarios.
CI targets Linux, macOS, and Windows with Python 3.11–3.13. Results qualify the
tested revision and platform; local success does not establish provider or
scientific behavior. Native qualification is tracked separately.

The design defines C01–C42. Unit coverage alone does not qualify their complete
transport, process, or provider behavior.

- **C01** — Submit the same command twice. Pending end-to-end evidence.
- **C02** — Reuse an idempotency key with changed payload. Pending end-to-end evidence.
- **C03** — Two workers claim one exclusive device. Pending end-to-end evidence.
- **C04** — Two campaigns reserve the final available budget. Pending end-to-end evidence.
- **C05** — A controller subprocess exits immediately after a committed report wakes a registered wait. Reopening delivers the saved notification; a lost receiver reply redelivers the same ID and creates one acknowledgment. Readiness remains separate from evidence consumption. Local process and API proof; hosted delivery remains separate.
- **C06** — Result arrives twice. Pending end-to-end evidence.
- **C07** — Old worker session publishes after a new fence. Pending end-to-end evidence.
- **C08** — Lease expires while the child still runs. Pending end-to-end evidence.
- **C09** — A saved single-command turn recovers the original target acknowledgment without invoking its planner again. Real Temporal Activities repeat the exact turn after a lost reply or timeout overlapping the original call, with one domain effect. Native attempts remain independently owned.
- **C10** — Cancellation is requested for an offline worker. Pending end-to-end evidence.
- **C11** — Worker reconnects after controller restart. Pending end-to-end evidence.
- **C12** — Artifact upload succeeds but result commit fails. Local CPU pipeline recovers publication without re-execution or duplicate settlement; remote-provider proof pending.
- **C13** — Required artifact is corrupt or absent. Pending end-to-end evidence.
- **C14** — Candidate changes a protected evaluator dependency. Pending end-to-end evidence.
- **C15** — A real CPU workload exits with code 7; its research observation has no score and resolves without a scientific rejection or promotion.
- **C16** — Candidate and comparator use different forbidden protocols. Pending end-to-end evidence.
- **C17** — Two promotions reference the same incumbent revision. Local concurrent commands select one incumbent and preserve the conflicting assessment.
- **C18** — Independent client connections race child creation against insufficient parent funds. Exactly one child/allocation commits; the rejected command leaves no child or creation charge. Public HTTP creation and unchanged-key replay also pass locally.
- **C19** — A real CPU child executes and receives an authenticated evaluation. Consumption appears in ancestor accounts before completion; atomic finalization releases only the remaining grant and records its settlement in the final report. A report-write failure rolls back child completion and ancestor release.
- **C20** — Equivalent evidence/context yields one observation identity. Independent principals race each greedy boundary with one admitted trial, one policy consumption, and one incumbent advance. Immutable pins recover the assessment-to-promotion-to-resolution gaps.
- **C21** — Recorded external responses survive reopening and preserve reported usage. The greedy driver recovers lost command replies at proposal, admission, observation, pin, assessment, commit, and resolution boundaries. Provider response loss before durable recording remains separate.
- **C22** — Seed changes between declared replicates. Pending end-to-end evidence.
- **C23** — Evaluation returns an incomplete panel. Local pipeline records incomplete evidence and does not make it rankable.
- **C24** — Protected evaluation times out after access. Pending end-to-end evidence.
- **C25** — A paused campaign transfers through a verified immutable checkpoint and one atomic epoch change. Original acknowledgments or absent-ack closure reconcile before successor startup; stale actors cannot resume control. Competing transfers, evidence changes, rollback, preserved child funding, and an HTTP successor resuming the original CPU trial are locally verified. Actual provider-to-provider deployment remains separate.
- **C26** — Expired cursors return an explicit typed gap over HTTP and SSE. A reader creates an authorized frozen snapshot, verifies bounded pages/chunks, and resumes after its exact watermark. Retention preserves permanent event/outbox/wait evidence. Local API/CLI/MCP proof.
- **C27** — Worker lacks a required isolation feature. Pending end-to-end evidence.
- **C28** — Process spawns a child and cancellation occurs. Pending end-to-end evidence.
- **C29** — Native clocks differ. Pending end-to-end evidence.
- **C30** — Shared SDK/HTTP command replay remains qualified. A scoped external MCP actor now controls baseline selection, proposal/source admission, observation, promotion, and a final report across subprocess restart. Native workers and an independent evaluator complete the actual CPU stages while the agent is disconnected. Same-principal CLI replay returns the original report without additional trials, attempts, or observation consumption. Local integrated proof.
- **C31** — Controller restarts with budget exhausted. Pending end-to-end evidence.
- **C32** — Scientific completion captures exact UNKNOWN custody and accounting, closes admission, and freezes the final report. Original late native evidence settles without successor execution; explicit resource closure preserves the original report, settles child funding once, and exposes current operational status. Local CPU, independent-connection, and HTTP/MCP/CLI proof; strict completion still refuses uncertainty.
- **C33** — Original late closure can be quarantined after an epoch change and explicitly reconciled without another execution. An acceptance-lease expiry policy is not yet defined; dispatch expiry remains the launch cutoff, so this criterion is only partially qualified.
- **C34** — Locally verified: exact ordinary publication, submission, and reconciliation acknowledgments replay after epoch change; ordinary replay does not reopen artifacts. Concurrent same-key acceptance wins over subsequent mutable preflight failure.
- **C35** — A training worker fabricates an evaluation ID. Local pipeline rejects worker publication and substitution of a training attempt.
- **C36** — Two controllers enroll the same exclusive device. Pending end-to-end evidence.
- **C37** — Cross-principal search CAS admits one trial and consumes one observation; losing responses and equivalent assessments remain evidence. Greedy resolves accepted selections after restart without duplicating incumbent movement. Portfolio qualification also proves that a third native workload starts while an original sibling remains alive, after another sibling promotes; two registered HTTP workers share one capacity ledger and a separate evaluator. This is process-overlap proof, not throughput scaling.
- **C38** — Corrections preserve evidence and suspend affected selection. Explicit abandonment of a selected trial records fresh closed evidence or verified pinned-comparator corrections, preserves original pins/metrics, and releases only the policy slot.
- **C39** — Independent writers commit during snapshot capture and between pages. Frozen records and budgets remain at the original watermark; subsequent events appear strictly after it. A retention pin prevents pruning the catch-up interval until explicit release or terminal expiry. Local SQLite and transport proof.
- **C40** — Retained artifacts outlive a completed job. Pending end-to-end evidence.
- **C41** — Exact completion replay and repeated explicit settlement with new delivery keys through a reopened runtime return one immutable receipt without changing ancestor consumption or release again. Local CPU and independent-connection proof; provider delivery remains separate.
- **C42** — Production Python and an independent ECMAScript process match 17 frozen edge-case payloads, exact canonical bytes, SHA-256 content digests, and domain-separated record digests. Node also verifies the Python assignment signature and rejects mutation. Local proof; this does not qualify a second worker or domain authority.
